# RocketIDE 1.0.0 for Windows x64

Download and extract [the complete portable ZIP](https://github.com/RyanEid06/Rocket-RocketIDE/releases/download/v3.0.0/RocketIDE-win-x64-1.0.0.zip), or download this branch and open `app/RocketIDE.exe`. Keep the entire app folder together; the executable needs the included runtime and debugger files. No separate .NET installation is required.

Install [Rocket 3.0.0](https://github.com/RyanEid06/Rocket-RocketIDE/releases/tag/v3.0.0), then choose Tools > Rocket SDK Settings and select its `bin/rocketc.exe` and `bin/rocket-lsp.exe`. The Rocket SDK is a separate download.

This branch contains consumer files only. Source, tests and release evidence are on [main](https://github.com/RyanEid06/RocketIDE/tree/main). RocketIDE is a Windows WPF application; Linux and macOS downloads are available for the Rocket language SDK.

Version: 1.0.0+f54a7b2cd72dabaa5a327b61685bf53bbe81d5d2. See RELEASE.json and SHA256SUMS.txt for identity and file integrity. The main branch contains the full developer source and latest fixes; this consumer branch contains the frozen app.
