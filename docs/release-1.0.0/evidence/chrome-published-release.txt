Rocket 3.0.0 and RocketIDE 1.0.0
Download the archive for your platform below. Keep every file in the extracted folder.
RocketIDE for Windows x64
Extract RocketIDE-win-x64-1.0.0.zip and open RocketIDE.exe. The package includes the .NET runtime and native debugger; a separate .NET installation is not required. Install the Windows Rocket SDK, then select its bin/rocketc.exe and bin/rocket-lsp.exe in Tools > Rocket SDK Settings.
Rocket language SDK
Native packages are available for Windows x64, Linux x64, Linux ARM64, and macOS Apple Silicon ARM64. The compiler is rocketc.exe on Windows and rocketc on Linux/macOS. Each SDK includes the language server, libraries, toolchain and PACKAGE.md setup instructions. macOS requires Xcode Command Line Tools. There is no Intel macOS SDK or Linux/macOS RocketIDE build in this release.
Verification and provenance

Full evidence and limitations are in the developer branch release report.
